Translations

Serving the website in more than one language is switched on from the .env file: 

# .env file
LOCALES=en,de,fr
LOCALE_REDIRECT=true

LOCALES is the list of languages, the first one being the default one which is served without a URL prefix. LOCALE_REDIRECT is optional and sends a visitor landing on the root of the website to the language of their browser. When LOCALES is not set, nothing changes. See the translations section for the details.
